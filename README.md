# Волшебная ракушка 🐚

Виджет из «Губки Боба» для Windows и Mac. Задай вопрос мысленно,
нажми на ракушку или потяни колечко вверх. Она ответит случайной фразой на русском.

## Скачать

[Последняя версия](https://github.com/urnurii/magic-conch-widget/releases/latest)

- **Windows 10/11 x64:** установщик `Setup.exe` или отдельный `Windows.exe` без установки.
- **macOS 11 и новее:** открой DMG и перенеси приложение в «Программы». Подходит для Intel и Apple Silicon.

Если в Windows нет WebView2, установщик скачает его.
Голос и ответы работают без интернета.

## Как пользоваться

- Нажми на ракушку или потяни колечко вверх и отпусти.
- Перемещай виджет за название или ручку `⠿`.
- `♫` включает и выключает звук, `⌖` закрепляет окно поверх других.
- `−` сворачивает, `×` закрывает приложение.

Встроены 12 ответов с женской русской озвучкой. Голосовые пакеты устанавливать не нужно.
Один ответ дважды подряд не повторяется. Положение окна и настройки сохраняются.

Версия 0.2.0 использует Tauri вместо Electron и не содержит встроенный Chromium.
Сборки пока без сертификата издателя. macOS может попросить разрешить запуск в настройках безопасности.
