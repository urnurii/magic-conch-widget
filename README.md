# Волшебная ракушка 🐚

Небольшой виджет для Windows по мотивам Magic Conch Shell из «Губки Боба».
Задай вопрос мысленно, нажми на ракушку или потяни колечко вверх и отпусти.
Ракушка выдаст случайный ответ на русском — как волшебный шар.

## Запуск

Для установки и отправки друзьям: `dist/Magic-Conch-0.1.1-Setup.exe`.
Это самостоятельный установщик для Windows 10/11 x64: дополнительные файлы, Node.js
и интернет для установки не нужны. Он устанавливает приложение для текущего пользователя
без прав администратора, позволяет выбрать папку и добавляет ярлыки на рабочий стол и в меню «Пуск».
Удаление доступно через «Установленные приложения» Windows.
Установщик не подписан цифровой подписью; Windows может показать предупреждение о неизвестном издателе.

Готовая версия: `dist/Magic-Conch-0.1.1-portable.exe`. Просто открой её двойным щелчком.
Установка, права администратора и Node.js для готовой версии не нужны.
Первый запуск может занять несколько секунд: portable-версия распаковывает Electron.

Для разработки установи Node.js 24+:

```powershell
npm install
npm start
```

## Управление

- Нажми на ракушку — получишь ответ после короткой анимации.
- Потяни колечко **вверх** минимум на 42 пикселя и отпусти. Короткая тяга не срабатывает.
- Ракушку и колечко можно активировать клавишами Enter/Пробел, выбрав их через Tab.
- Переноси окно за название сверху или за ручку `⠿` снизу.
- `♫` включает/выключает звуковой сигнал и озвучку.
- `⌖` переключает отображение поверх других окон.
- `−` сворачивает виджет в панель задач, `×` полностью закрывает.

Положение окна, звук и закрепление сохраняются между запусками в пользовательской папке приложения (`app.getPath('userData')`). Второй запуск возвращает уже открытый виджет.

В наборе 12 ответов: «Да», «Нет», «Не знаю», «Подумай сам», «Ничего» и другие.
Один и тот же ответ не выпадает дважды подряд. Вопрос вводить не нужно.

## Звук

Виджет создаёт короткий звуковой сигнал локально. Для чтения ответа используется установленный **локальный русский голос Windows**, если он доступен через Speech Synthesis.
При отсутствии такого голоса ответы остаются текстовыми; подсказка в виджете сообщает об этом.
Это системный голос, а не оригинальная озвучка мультфильма. Все функции работают без подключения к интернету.

## Проверка и сборка

```powershell
npm test
npm run build
```

`npm run build` создаёт portable-версию и установщик; `npm run build:installer` — только установщик.

Тесты проверяют набор ответов, отсутствие повторов, настоящее прозрачное окно и PNG,
нажатие, порог тяги и её отмену, клавиатуру, закрепление и сохранение настроек.
Для UI-тестов используется Electron через Playwright; браузер отдельно устанавливать не нужно.
Проверить уже упакованное приложение можно так:

```powershell
$env:CONCH_PACKAGED_EXECUTABLE = (Resolve-Path 'dist/win-unpacked/Magic Conch.exe').Path
node test/widget.smoke.cjs
Remove-Item Env:CONCH_PACKAGED_EXECUTABLE
```

23 октября 2026 года проверки исходного и упакованного приложения успешно прошли на Windows x64.

## Устройство проекта

- `src/main.cjs` — прозрачное окно Electron, настройки и жизненный цикл.
- `src/preload.cjs` — ограниченный интерфейс между окном и ОС.
- `src/renderer.js` — вытягивание колечка, ответы, анимация и звук.
- `src/answers.js` — список фраз и случайный выбор.
- `assets/magic-conch.png` — исходная ракушка с настоящей прозрачностью.
- `SOURCES.md` — источники и сведения о правах на материалы.
- `ROADMAP.md` — следующие улучшения.

Это первая версия для Windows x64. Виджет является обычным прозрачным окном;
он не встраивается в слой обоев Windows. Пустые области прямоугольника окна могут перехватывать мышь.
Пользовательский размер пока фиксирован. Бинарник не подписан цифровой подписью.
В текущей тестовой сессии Windows сбрасывает закрепление поверх других окон даже у минимального окна Electron.
Если ОС отклоняет закрепление, кнопка остаётся выключенной, а виджет сообщает об этом.
Постоянное закрепление требует дополнительной проверки в обычной сессии Windows.

## Репозиторий

Локальный Git-репозиторий, основная ветка `main`. Зависимости и готовые сборки исключены из Git.
Для повторяемой установки включён `package-lock.json`. Публикация на GitHub пока не настроена.

Материалы мультфильма не распространяются под лицензией исходного кода; см. `SOURCES.md`.
