# Источники материалов

## Ракушка

- [Страница изображения](https://www.emojisky.com/desc/305847).
- [Оригинальный PNG](https://image.emojisky.com/847/305847.png).
- Файл: `assets/magic-conch.png`, 424 × 463 пикселя, прозрачный фон.
- На сайте указано использование в некоммерческих проектах. Автор иллюстрации не указан.
- Персонажи и объекты SpongeBob SquarePants принадлежат их правообладателям.

PNG не изменён. Маска в CSS скрывает исходное колечко и свободную часть шнурка,
сохраняя корпус и крепление. Подвижные колечко и верёвочка сделаны средствами CSS и SVG.
Иконки приложения получены из этой же картинки через `tauri icon scripts/app-icon.svg`.

## Голос

В `assets/audio/` находятся 12 готовых записей на русском.
Голос: Microsoft `ru-RU-SvetlanaNeural`, темп `-8%`.
Записи созданы с помощью [edge-tts](https://github.com/rany2/edge-tts), версия 7.3.1.
Тексты и контрольные суммы указаны в `assets/audio/manifest.json`.

Генерация выполняется разработчиком один раз через онлайн-сервис.
Приложение проигрывает готовые файлы локально, не отправляет вопросы в сеть
и не требует установки голосов. Это синтезированная речь, а не голос из мультфильма.
